# Assets

Media EOX uses but doesn't generate: textures, skyboxes, terrain heightmaps,
visual meshes for the simulator. None are bundled yet.

## Third-party assets

Put each one in its own folder, `assets/third_party/<name>/`, with:

- the file(s), unmodified or with your changes noted;
- `LICENSE`: the asset's licence text, or a link to it if the licence is standard;
- `SOURCE.md`: where it came from (URL), who made it, the date you got it, and what you changed.

Then add a line to [CREDITS.md](../CREDITS.md).

**Licences we accept** (they allow use in an open-hardware project anyone may build and sell):

- CC0 / public domain (e.g. Poly Haven textures and HDRIs; USGS 3DEP elevation data)
- CC-BY 4.0 (credit the author in CREDITS.md)
- CC-BY-SA 4.0 (credit; changes to the asset stay CC-BY-SA)
- MIT, Apache-2.0, BSD and similar permissive software licences

**Licences we don't accept:**

- anything "non-commercial" (CC-BY-NC, CC-BY-NC-SA) or "editorial use only";
- GrabCAD community models (commercial use needs each designer's written permission);
- "royalty free" marketplace licences that forbid redistribution of the files;
- models carrying a brand's name, logo or livery (trademarks), whatever the mesh licence.

Our own licence doesn't change any of this: a third-party asset's licence
travels with it.
